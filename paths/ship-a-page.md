# Ship a page

Something a person can open.

You leave with one page that reads well on a phone, one piece of behavior, and the ability to point at the line that does it.

About 65 minutes, if you make the thing.

1. **[HTML & CSS](../languages/html-css.md).** The page is the product. Get the meaning and the layout right before any logic.
2. **[JavaScript](../languages/javascript.md).** Add one behavior: filter, submit, or fetch. Keep it in the same file.
3. **[TypeScript](../languages/typescript.md).** Only after something works. Use it to check the code, not to start over.

## Stop when

A person can open it on a phone, use the one action, and you can name the function that handles it.
