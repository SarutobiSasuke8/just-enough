# Review the agent

Read code you did not write.

You leave able to reject a snippet for a specific reason — a wrong length, an invented field, a null, a command you will not run.

About 55 minutes, if you make the thing.

1. **[How to read](../review.md).** Six habits. This is the skill that compounds, because every language uses it.
2. **[TypeScript](../languages/typescript.md).** The checker is a second reader. Learn what it is pointing at.
3. **[JavaScript](../languages/javascript.md).** Most of what you are handed is JavaScript. filter and map are the usual fault line.

## Stop when

You can say what is wrong in one sentence, and what you would ask the model to change — not “make it better.”
