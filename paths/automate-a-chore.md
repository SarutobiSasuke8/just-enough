# Automate a chore

A script you can run again.

You leave with a script that reads a copy of a real file, writes a new file, and tells you what it skipped.

About 50 minutes, if you make the thing.

1. **[Python](../languages/python.md).** The chore itself. Lists, dicts, files, and a printed count.
2. **[The shell](../languages/shell.md).** So you can run it from the right folder and refuse a dangerous command.
3. **[SQL](../languages/sql.md).** Only if the chore is a question about rows. Otherwise stop after the shell.

## Stop when

You ran it on a copy, read the kept and skipped counts, and can say what the script will not touch.
